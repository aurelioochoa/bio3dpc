# README banner artwork

`media/banner.png` was generated with the built-in image generation tool.
It uses the project's generated `bio3dpc/ui_assets/bathysphere-source.png`
and `bio3dpc/ui_assets/bathysphere-logo-source.png` as environment and
typography references. It is presentation artwork, not a gameplay capture.

The banner replaces the original vector illustration with realistic brass,
patinated metal, underwater lighting and the Art Deco skyline of Rapture.
